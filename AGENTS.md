# Reglas de Gobernanza del Proyecto: Dieta & Fitness Mobile

Este proyecto sigue estrictamente el flujo de desarrollo colegiado y las directrices documentadas en [.agents/rules/development-workflow.md](file:///d:/Proyectos_python/Proyectos_AI/Aplicaciones_mobile/Dieta/.agents/rules/development-workflow.md).

## Principios Obligatorios:
1. **Confirmación del Usuario:** No realizar cambios de código o estructura sin autorización expresa.
2. **Ejercicios sin Máquinas:** Solo mancuernas, ligas de resistencia, bandas para piernas, cardio y peso corporal.
3. **Alimentación Realista y Económica:** Desayuno, Comida, Cena y Snacks con ingredientes comunes, cero gourmet.
4. **Métricas Científicas:** IMC y peso diferenciando hombre y mujer.
5. **Flujos Obligatorios:** Seguir el flujo estipulado según si es Feature, Bugfix, Mejora UI o Contenido.
